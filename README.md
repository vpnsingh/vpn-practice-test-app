## About

CredPilot is a browser-based certification practice app built with React and Vite. Choose an exam track, work through practice questions, or use study mode to review questions and answers at your own pace.

### Exam tracks

| Track | What you can do |
| --- | --- |
| Claude Certified Associate | Practice or study available question sets |
| Claude Certified Developer Foundations (CCDV-F) | Practice or study available question sets |
| GitHub Copilot (GH-300) | Practice by exam part or study questions by section |

## Features

- One question at a time with previous and next navigation
- Practice mode with answer checking and a final score summary
- Study mode with answers shown and questions organized for review
- Support for single-answer and multiple-answer questions
- Results include correct and incorrect counts, percentage, and pass status
- Downloadable PDF results and question sets
- 80% passing threshold

## Run locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open the local URL printed in the terminal.
