# VPN Practice Test App

A React VPN practice test application built with Vite.

## Features
- One question displayed at a time
- Supports 4-5 options per question
- Check answer inline on the same screen
- Previous / Next navigation
- Final score summary with percentage, correct, incorrect, and pass/fail status
- Passing threshold set to 80%

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```
3. Open the app in your browser at the local address shown in the terminal.
